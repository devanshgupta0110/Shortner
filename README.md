## Overview

Shortner is a powerful URL shortening service designed to streamline link sharing, management, and analytics within a secure and scalable architecture. Built with ASP.NET Core, Entity Framework Core, and Identity, it offers a modular solution for generating, storing, and resolving shortened URLs seamlessly.

**Why Shortner?**

This project empowers developers to implement reliable URL redirection, user authentication, and role-based access control with ease. The core features include:

- 🧩 **Modular Architecture:** Supports URL shortening, redirection, and data management in a clean, maintainable structure.
- 🚀 **Fast URL Redirection:** Efficiently resolves short URLs to their original links, tracking click counts.
- 🔐 **Secure User Management:** Integrates authentication, role management, and user-specific URL tracking.
- 🛠️ **Developer-Friendly:** Includes seed data for roles/users, validation, and comprehensive API endpoints.
- 🎯 **Scalable & Extensible:** Designed for growth with a focus on performance and maintainability.

## Getting Started

### Prerequisites

This project requires the following dependencies:

- **Programming Language:** CSharp
- **Package Manager:** Nuget

### Installation

Build Shortner from the source and install dependencies:

1. **Clone the repository:**

    ```sh
    ❯ git clone https://github.com/devanshgupta0110/Shortner
    ```

2. **Navigate to the project directory:**

    ```sh
    ❯ cd Shortner
    ```

3. **Install the dependencies:**

**Using [nuget](https://docs.microsoft.com/en-us/dotnet/csharp/):**

```sh
❯ dotnet restore
```

### Usage

Run the project with:

**Using [nuget](https://docs.microsoft.com/en-us/dotnet/csharp/):**

```sh
dotnet run
```

### Testing

Shortner uses the {__test_framework__} test framework. Run the test suite with:

**Using [nuget](https://docs.microsoft.com/en-us/dotnet/csharp/):**

```sh
dotnet test
```
